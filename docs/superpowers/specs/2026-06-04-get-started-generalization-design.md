# Get Started 通用化设计

**日期:** 2026-06-04
**目标:** 新用户 clone 仓库后，填 4-5 个环境变量即可一键部署 SmartNPC 全套（Docker-only 模式）。

---

## 1. 最小 `.env.example`

新用户只需关注两个区域：

```ini
# ══ 必填 ══════════════════════════════════════════════════════════
# Stardew Valley 安装路径（含 StardewModdingAPI.exe）
SMARTNPC_GAME_PATH=D:\Stardew Valley

# LLM 配置（Hermes Agent 调用的大模型）
HERMES_AGENT_URL=https://api.deepseek.com
HERMES_AGENT_API_KEY=sk-YOUR_KEY_HERE
HERMES_AGENT_MODEL=deepseek-v4-pro

# ══ 可选（有合理默认值，通常不需要改） ════════════════════════════
# MCP HTTP 端口（默认 3000）
# SMARTNPC_HTTP_PORT=3000

# 启动哪些 NPC（默认全部 6 个）
# SMARTNPC_ACTIVE_PROFILES=xiami,abigail,haley,harvey,penny,sebastian

# WSL 发行版名（默认 Ubuntu-22.04，`wsl -l -v` 查看）
# WSL_DISTRO=Ubuntu-22.04

# Hermes gateway 启动超时（秒，默认 90）
# HERMES_BOOT_TIMEOUT=90

# ══ 高级可选（Langfuse 观测） ════════════════════════════════════
# HERMES_LANGFUSE_PUBLIC_KEY=pk-lf-xxx
# HERMES_LANGFUSE_SECRET_KEY=sk-lf-xxx
# HERMES_LANGFUSE_BASE_URL=http://langfuse:3000
```

**被移除的变量（不再需要用户配置）：**
- `SMARTNPC_HERMES_MODE` — 固定 docker
- `SMARTNPC_HERMES_GATEWAY_HOST` / `WIN_HOST_IP` / `WSL_IP` — 自动探测
- `SMARTNPC_MCP_URL` — 自动从 `WIN_HOST_IP` + `SMARTNPC_HTTP_PORT` 拼接
- `SMARTNPC_HERMES_KEY` — 硬编码默认值 `smartnpc-test-key`（本地开发无需改）

## 2. `setup.bat` — 一键注入脚本

**位置:** 仓库根 `setup.bat`
**运行时机:** 首次部署 / `hermes/` 目录有变更 / LLM 凭据变更

### 流程

```
setup.bat
├─ [1] 定位仓库根（%~dp0），加载 .env
├─ [2] 前置条件检查
│      ├─ wsl 可用？
│      ├─ wsl 内 docker 可用？
│      └─ SMARTNPC_GAME_PATH 目录存在？
├─ [3] 渲染 profiles
│      └─ powershell -File scripts/render_profiles.ps1
├─ [4] 探测 WSL IP
│      └─ wsl bash scripts/detect_wsl_ips.sh → 设 WIN_HOST_IP
├─ [5] 动态生成 deploy/hermes/docker-compose.yml
│      └─ powershell -File scripts/generate_compose.ps1
├─ [6] 生成 deploy/hermes/.env
│      ├─ SMARTNPC_MCP_URL=http://{WIN_HOST_IP}:{HTTP_PORT}/mcp
│      ├─ SMARTNPC_HERMES_KEY=smartnpc-test-key
│      ├─ HERMES_AGENT_URL / API_KEY / MODEL
│      └─ HERMES_LANGFUSE_* (if set)
├─ [7] WSL 内执行：sync-profiles.sh + docker compose build
└─ [8] 打印完成信息
```

### 前置条件检查细节

```bat
rem 检查 WSL 可用
wsl --status >nul 2>&1
if errorlevel 1 (echo [ERROR] WSL not available. && exit /b 1)

rem 检查 WSL Docker
wsl -d %WSL_DISTRO% docker info >nul 2>&1
if errorlevel 1 (echo [ERROR] Docker not available in WSL. && exit /b 1)

rem 检查游戏路径
if not exist "%SMARTNPC_GAME_PATH%\StardewModdingAPI.exe" (
    echo [ERROR] StardewModdingAPI.exe not found in %SMARTNPC_GAME_PATH%
    exit /b 1
)
```

### 幂等性

多次运行安全：
- `render_profiles.ps1` 覆盖写
- `generate_compose.ps1` 覆盖写
- `deploy/hermes/.env` 覆盖写
- `docker compose build` 有缓存，未改动时秒过

## 3. `scripts/generate_compose.ps1` — 动态生成 docker-compose

**输入:** `hermes/npcs.yaml`
**输出:** `deploy/hermes/docker-compose.yml`

从 `npcs.yaml` 读取所有 `enabled: true` 的 NPC，为每个生成一个 service 定义：

```powershell
# 伪代码逻辑
foreach ($npc in $enabledNpcs) {
    # service name: hermes-{id}
    # container_name: hermes-{id}
    # environment: NPC_PROFILE={id}, NPC_PORT={gateway_port}
    # ports: {gateway_port}:{gateway_port}
    # healthcheck: curl http://localhost:{gateway_port}/health
}
```

输出文件头部带注释警告：
```yaml
# AUTO-GENERATED by setup.bat — do not edit manually.
# Source: hermes/npcs.yaml
# Regenerate: run setup.bat
```

## 4. `run.bat` 改造

### 删除项
- `SMARTNPC_HERMES_MODE` 分支（local_setup / docker_setup）
- Step 4.5 渲染 profiles（移到 setup.bat）
- `docker compose build`（移到 setup.bat）
- `:wait_one_profile` 中的 6 行 hardcoded 端口映射

### 新增项
- **步骤 2（新）：** 从 `npcs.yaml` 动态解析 NPC→端口映射
- **前置校验：** `deploy/hermes/docker-compose.yml` 不存在时报错并提示先跑 `setup.bat`
- **前置校验：** `.env` 中 `SMARTNPC_GAME_PATH` 必须设置

### 端口动态解析

```bat
rem 解析 npcs.yaml → %TEMP%\smartnpc_ports.txt (格式: id=port)
powershell -NoProfile -Command ^
  "switch -Regex -File '%SMARTNPC_REPO%\hermes\npcs.yaml' { ^
    '^\s*- id:\s*(\S+)' { $id=$Matches[1] } ^
    '^\s*gateway_port:\s*(\d+)' { \"$id=$($Matches[1])\" } ^
  }" > "%TEMP%\smartnpc_ports.txt"
```

`:wait_one_profile` 改为从该文件查端口：
```bat
:wait_one_profile
set "_p=%~1"
set "_port="
for /f "tokens=1,2 delims==" %%A in ('findstr /i "^%_p%=" "%TEMP%\smartnpc_ports.txt"') do set "_port=%%B"
if not defined _port (
    echo [WARN] unknown profile '%_p%' — skip
    goto :eof
)
rem ... 后续健康检查逻辑不变
```

### 改造后流程

```
run.bat
├─ [1] 加载 .env + 设默认值
├─ [2] 前置校验（.env 完整性 + docker-compose.yml 存在）
├─ [3] 从 npcs.yaml 解析端口映射
├─ [4] 探测 WSL IP
├─ [5] Build mod + mcp
├─ [6] Kill old processes
├─ [7] Install mod
├─ [8] Start mcp (--http 模式)
├─ [9] docker compose up -d（WSL 内，不 build）
├─ [10] 等待 gateway healthy（端口动态查询）
└─ [11] Launch game
```

## 6. 新用户完整 Get Started

```
前提条件：
  - Windows 10/11 + WSL2（Ubuntu）
  - WSL 内已安装 Docker Engine
  - Go 1.22+、.NET SDK 8.0、Git

步骤：
  1. git clone https://github.com/OmniStormX/SmartNPC
  2. cd SmartNPC
  3. copy .env.example .env
  4. 编辑 .env：填写 SMARTNPC_GAME_PATH + HERMES_AGENT_URL/API_KEY/MODEL
  5. setup.bat            ← 构建 Hermes Docker 镜像（首次 ~3-5 min）
  6. run.bat              ← 编译 + 启动全套 + 启动游戏
  7. 进入游戏，按 Tab 打开聊天面板

后续维护：
  - 改了 hermes/ 下任何文件 → 重跑 setup.bat
  - 改了 Go/C# 代码 → 只需 run.bat
  - 换 LLM → 改 .env 后重跑 setup.bat
```
